## FlowMQ 1.5.0

- Add single-broker MDP over TCP, WebSocket, KCP and IPC, with multiple Worker listeners and bounded peer capacity.
- Add JSON-RPC request and batch dispatch, configurable Worker placement and queue policies, deferred downstream orchestration, and per-member fanout results.
- Add a CFlow Statechart example that joins price and delivery calls and demonstrates concurrent requests and cancellation.
- Add durable one-way delivery with a TurboDB ORM SQLite outbox and inbox.

The release includes native SDK archives for Windows x64, Linux x64, macOS ARM64, and Android ARM64. The archives contain CMake package metadata and an SDK manifest listing the selected dependency versions. Android is qualified by cross-build and install. Use `SHA256SUMS` to verify the downloaded archives.

The MDP broker scope is one broker. Cross-broker Raft coordination and durable workflow recovery remain design items.
